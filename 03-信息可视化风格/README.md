### A. 数据逻辑与导入

1. **输入途径。** 粘贴、文本文件上传、示例、SPARQL SELECT、URL 和打开 `.rawgraphs` 工程是六个界面入口。上传调用 `FileReader.readAsText`，实际数据解析走分隔文本或 JSON。上传的 MIME 列表含 `application/vnd.ms-excel`，这段代码只验证了文本读取路径，调研未发现 XLSX 工作簿解析器。URL 直接由浏览器读取，受目标服务器 CORS 约束。SPARQL 客户端向端点提交查询，将返回的绑定按变量整理为行。[src/components/DataLoader/DataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataLoader/DataLoader.js#L69-L166)、[src/components/DataLoader/loaders/UploadFile.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataLoader/loaders/UploadFile.js#L11-L34)、[src/components/DataLoader/loaders/UrlFetch.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataLoader/loaders/UrlFetch.js#L5-L8)、[src/components/DataLoader/loaders/SparqlFetch.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataLoader/loaders/SparqlFetch.js#L47-L62)、[src/components/DataLoader/loaders/SparqlFetch.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataLoader/loaders/SparqlFetch.js#L163-L177)
2. **格式探测、表格化。** 探测按带标记的 SPARQL 结果、JSON、DSV 的次序尝试。DSV 使用 D3 解析，手工指定的分隔符优先，自动模式按候选首行可解析的字段数取高分。JSON 的交互选取路径要求数组，数组行可生成 `Column 1` 等字段，内部数组仅保留标量并用空格连接，内层对象的标量属性展开成点号键。原始 JSON 的层次可能在这一步折叠。[src/hooks/useDataLoaderUtils/parser.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoaderUtils/parser.js#L4-L79)、[src/hooks/useDataLoaderUtils/parser.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoaderUtils/parser.js#L102-L139)、[src/hooks/useDataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoader.js#L265-L297)
3. **类型化。** Core 在未给定类型时检查各行同名字段，按最频繁的候选类型决定列类型。数字解析可用小数/千位分隔和区域选项，日期可用格式和区域配置。逐行转换记录单元格错误，移除所有转换值均为空的行，返回 `dataset`、`dataTypes`、`errors`。表格的手工类型覆写与行内编辑会进入重新解析流程。[src/dataset.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/dataset.js#L15-L132)、[src/dataset.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/dataset.js#L153-L210)、[src/dataset.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/dataset.js#L240-L303)、[src/hooks/useDataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoader.js#L305-L406)
4. **整形与替换。** Stack 操作保留选定的标识列，把其余列逐个拆成 `column`（旧列名）与 `value`（单元格值），相当于宽表转长表，撤销时回用原表。替换模式会比较新旧列名，并在列匹配的路径中保留已有类型覆盖。[src/hooks/useDataLoaderUtils/stack.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoaderUtils/stack.js#L3-L14)、[src/hooks/useDataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoader.js#L170-L229)、[src/hooks/useDataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoader.js#L409-L431)

**设计推断。** 先记录“一行代表什么”，再选择统计操作。像 `0017` 这类编号，以及以 `2025` 表示的年份或分类标签，导入前应明确其语义。宽表转长表会改变行粒度，按行计数和求和之前要重新确认分母。

### B. 字段映射与统计操作

- **源码事实｜字段与图形角色。** 每个图表用 `dimensions` 声明角色及其必填性、可接受列类型、是否接受多列和数量约束。拖放时，App 把列名写到维度的 `value`，同时维护项目 ID、显示用类型信息和可选聚合配置。Core 校验字段和角色的兼容性，归一化单/多列映射，并标注数据类型，再把映射传给图表实现。[src/components/DataMapping/ChartDimensionCard.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataMapping/ChartDimensionCard.js#L37-L76)、[src/components/DataMapping/DataMapping.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/DataMapping/DataMapping.js#L90-L164)、[src/mapping.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/mapping.js#L72-L206)、[src/alluvialdiagram/dimensions.js](https://github.com/rawgraphs/rawgraphs-charts/blob/265a80e0da305c17df06f6a175713b8dbcbbb2bc/src/alluvialdiagram/dimensions.js)
- **源码事实｜计算有两条路径。** 图表可提供映射对象，让 Core 执行取字段、分组、汇总等声明式操作，也可提供自定义函数，按自身的数据结构重组原始行。Bubble chart 用 `get` 读取 x、y、size 等字段。Bar chart 按系列和类别聚合，Size 未映射时用组内行数，映射后对值调用聚合器。Alluvial 将相邻阶段两两配对并汇总。Core 的聚合注册表包括行数、去重计数、和、平均值与中位数，可选项仍受对应维度约束。[src/rawGraphs.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/rawGraphs.js#L220-L276)、[src/mapping.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/mapping.js#L262-L370)、[src/mapping.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/mapping.js#L372-L554)、[src/expressionRegister.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/expressionRegister.js#L61-L146)、[src/bubblechart/mapping.js](https://github.com/rawgraphs/rawgraphs-charts/blob/265a80e0da305c17df06f6a175713b8dbcbbb2bc/src/bubblechart/mapping.js)、[src/barchart/mapping.js](https://github.com/rawgraphs/rawgraphs-charts/blob/265a80e0da305c17df06f6a175713b8dbcbbb2bc/src/barchart/mapping.js#L26-L48)、[src/alluvialdiagram/mapping.js](https://github.com/rawgraphs/rawgraphs-charts/blob/265a80e0da305c17df06f6a175713b8dbcbbb2bc/src/alluvialdiagram/mapping.js)
- **设计推断｜数量的口径。** 假设 A 类两行金额为 2、3，B 类一行金额为 4。Bar chart 只映射 Bars 时，柱长表示 A=2、B=1 条记录。将金额映射到 Size 并选 Sum 后，变为 A=5、B=4。视觉形式相同，统计量与单位已经改变。这个例子是按代码推演，可据此核对映射记录与轴标题。

### C. 视觉编码、布局与渲染

### D. 输出、项目复用与扩展

- **源码事实｜图形。** SVG 路径序列化预览容器的第一个节点后下载。PNG/JPG 将序列化 SVG 载入 `Image`，绘至按节点显示尺寸创建的 Canvas，再生成对应的图片。由此可区分可继续编辑的 SVG 和像素化的输出。[src/components/Exporter/Exporter.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/Exporter/Exporter.js#L14-L89)
- **源码事实｜项目。** `.rawgraphs` 是 JSON。Core 当前默认写入 1.2，可读取注册的 1、1.1、1.2 格式。1.2 保存原始输入、数据来源、表格矩阵、解析参数、类型、图表 ID、映射、视觉选项和自定义图表信息。App 恢复数据与映射时会按已存配置重新解析。若把工程当作研究附件，应了解它会携带原数据。[src/App.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/App.js#L172-L249)、[src/hooks/useDataLoader.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useDataLoader.js#L135-L167)、[src/importExport/index.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/importExport/index.js#L1-L49)、[src/importExport/importExportV1.2.js](https://github.com/rawgraphs/rawgraphs-core/blob/715cc49e2c98f2171aa818f5600817db9a4b3cd6/src/importExport/importExportV1.2.js#L7-L59)
- **源码事实｜扩展与网络边界。** 自定义图表有本地文件、URL、npm 三种载入来源。核心制图链路在浏览器中执行，远程数据、SPARQL 和扩展加载使用网络。源码还在 `gtag` 可用时上报图表 ID 与导出格式等事件字段。远程加载条件与图表包的依赖情况会影响一份工程能否独立重现。[src/hooks/useCustomCharts.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useCustomCharts.js#L191-L271)、[src/hooks/useSafeCustomCharts.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/useSafeCustomCharts.js#L52-L152)、[src/hooks/rawRequire.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/hooks/rawRequire.js#L226-L283)、[src/gaEvents.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/gaEvents.js#L20-L45)

### E. 在知识库里记录视觉叙事

**设计推断。** 把 RAWGraphs 输出当作信息图形中的一层。先记行粒度和聚合口径，再记主编码、可修饰属性、布局排序和读者的阅读方向。图表已有轴或图例时，研究记录仍可标出原始单位、时间窗和分母，以及导出后新增的标题、标注、分组或裁切。案例可用拟合的图形模型说明构图机制，识别作品的数据逻辑与表现类型时仍以对应案例证据为准。[数据逻辑入口](../01-信息图形数据逻辑/01-编年型信息图形概念定义.md) · [表现类型与案例索引](../02-信息图形类型案例/案例索引.md)
