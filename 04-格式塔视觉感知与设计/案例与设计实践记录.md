# 格式塔案例与设计实践记录

按「可观察的线索 → 推断的感知组织 → 实际读图或测试」记录一个案例。案例分析识别的是可见的设计机制。作品的设计意图、读者反应及统计关系各用相应的证据确认。

## 经典观察

### 接近律 · Wertheimer 的点列

**可见事实**。原文用相同符号组成点列，改变相邻点的间隔。一个点列可因此被看成若干对。后续图例再调整点的相似性，形成支持同一分组或支持竞争分组的布局。 [Wertheimer，1923，英译第 I–III 节](https://psychclassics.yorku.ca/Wertheimer/Forms/forms.htm)

**设计分析**。在一排同质元素中，相对间距可以直接承担分组。照片、数字和它们的标签若形成同样的局部距离关系，也能据此建立归属。先检查同组对象的距离，再检查不同类别是否因颜色或对齐被误配。

### 图形—背景 · Rubin 的杯与侧脸

**可见事实**。原图中央轮廓可读为一个杯形，也可把两侧读为面对面的侧脸。共享边缘会随前景判断而改变归属。 [Rubin，1915，图 3](https://www.kb.dk/e-mat/dod/111408024790-bw.pdf)

**设计分析**。在信息图中，轮廓、对比或留白都可能让背景反客为主。可用「先看到的是数据标记、底图还是装饰」检查版面的主体是否与读图任务一致。

## 已核对的信息图案例

### 伦敦交通线路图 · Transport for London

**读者任务**。从起点找到可沿线到达的站点，再识别可换乘的位置。

**可见事实**。线路图用颜色与线型区分服务。图例区分换乘站、站内换乘和短距离步行连接。相邻站点分布在线路上。 [Transport for London 线路图](https://content.tfl.gov.uk/standard-tube-map.pdf)

**设计分析**。同色同线型提供相似性，连续线路便于沿路径追踪，连接和换乘符号提供不同读图线索。靠近且交叉的线段容易被读者联想为可互换关系，具体换乘仍要对照图例。从图面可核对以上线索，乘客实际如何阅读需要另行观察。

**实践经验**。绘制自己的网络图时，给出一对起点和终点，要求读者沿图找路径并说出可换乘的位置。记录在哪个交叉点犹豫、把哪条线接错、是否能区分步行连接。可用同一份网络数据试画两个版本，单独调整交叉点表达，再比较错误位置。

## 版式练习 · 图注归属

选两张相邻图片，各配一条图注。保持文字、颜色、图片尺寸一致。

1. 版本 A 让两条图注与左右图片接近程度相似。
2. 版本 B 把图注移近所属图片，同时拉开两组之间的间距。
3. 请读者指出图注所属图片。记录配对正确数、读者犹豫的位置和输出尺寸。需要进一步判断时，可做第三个版本，加底色边界测试共同区域。
4. 若两种线索给出不同归属，回到读者任务选一个明确的主线索。保留测试版本、实际观察与最后采用的做法。

这是可执行的版式对照练习，实际结果由测试后记录。

## 后续案例记录模板

| 记录项 | 内容 |
| --- | --- |
| 作品与来源 | 案例 ID、作者或发布方、版本、来源链接、所用图像及授权状态。 |
| 任务与场景 | 读者要分组、找路径、定位、比较，还是辨认主体？ |
| 可见事实 | 圈出元素、间距、共享边界、颜色、线条或变化时点。动态案例可记时间戳。 |
| 设计分析 | 写出主线索和次线索，说明哪一处支持判断，哪些线索可能互相干扰。 |
| 改版与测试 | 对照版本、控制的变量、读者任务、实际反应和错误位置。 |
| 经验与边界 | 哪个做法适用于什么版式、媒介和任务，哪一处还有反例或待核证据？ |
