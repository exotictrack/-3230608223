# 04 格式塔视觉感知与设计

格式塔（Gestalt）视觉感知研究解释读者如何把图上的元素看成一组、把轮廓看成整体，以及从背景中读出主体。这里将它用于信息图形的版面组织、关系表达和阅读路径分析。登记案例时，可在数据逻辑和表现类型之外，补充实际可观察的感知线索。

- [格式塔原则定义与设计应用](格式塔原则定义与设计应用.md)涵盖 14 个条目，有中英文名、定义、可复现的设计示例和误读边界。
- [案例与设计实践记录](案例与设计实践记录.md)收录经典感知实例、一个公开信息设计案例、版式对照练习和后续记录模板。

## 收录范围与定位

本专题属于视觉感知与设计基础，服务于多种信息图形类型。Gestalt 原则没有统一、封闭的总数；本目录采用 **7 项经典分组线索＋5 项后续线索与扩展＋2 项总体概念，共 14 个研究条目**，不表示“格式塔只有 14 条定律”。分类依据见 [Wagemans 等，2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/)。这些原则是受情境影响的知觉倾向，不能机械视为必然成立的排版公式。

本目录保持编号 `04`；具体项目继续在 [05-XXX主题信息图形设计](../05-XXX主题信息图形设计/README.md) 中记录。

## 文档记录规范

各专页记录定义与概念、案例、设计分析、设计实践、经验与边界。案例注明作品、作者、出处和可观察证据；教学示例明确标注；实践记录包含修改前后版本、控制变量、测试条件与读者反馈。未经测试的建议不得写成已验证经验。详细模板见 [案例与设计实践记录](案例与设计实践记录.md)。
