# 04 格式塔视觉感知与设计

格式塔（Gestalt）视觉感知研究解释读者如何把图上的元素看成一组、把轮廓看成整体，以及从背景中读出主体。这里将它用于信息图形的版面组织、关系表达和阅读路径分析。登记案例时，可在数据逻辑和表现类型之外，补充实际可观察的感知线索。

- [格式塔原则定义与设计应用](格式塔原则定义与设计应用.md)涵盖 14 个条目，有中英文名、定义、可复现的设计示例和误读边界。
- [案例与设计实践记录](案例与设计实践记录.md)收录经典感知实例、一个公开信息设计案例、版式对照练习和后续记录模板。
