# 06 视觉编码

先从叙事里选出需要突出、比较或定位的信息，再确定图形语言。编码表应让读者看到某种位置、长度、色彩或图形时，知道它代表哪个字段、类别或数值。

| 设计表达 | 可考虑的用法 | 需要核对的事项 |
| --- | --- | --- |
| 点、线、面、体 | 点表示位置或事件；线表达连接、路径或变化；面表达区域或规模；体可表现实体形态、体积或空间关系。 | 核对几何特征与数据语义，使用面积或体积表示数值时检查比例及遮挡。 |
| 色彩 | 用色相区分类别，用有序的明度变化表达高低，用强调色引导视线。 | 写明色彩对应的类别、范围或重点，检查对比度与色觉可辨性。 |
| 字体、字号、行距、字距 | 用标题、正文、注释建立阅读层次；用行距、字距和段落间隔调整节奏。 | 在成品尺寸检查可读性。若字号承载词频等数值，记录字号与权重的映射方式。 |
| 图像与图形 | 照片提供对象与环境细节，插图或抽象图形突出结构，必要时搭配图注。 | 保留出处，检查裁切会否丢失关键证据，明确每张图的叙事工作。 |
| 统计图形 | 条形的长度便于比较，时间尺度上的位置可呈现变化，地图点位可呈现分布。 | 标明量表、单位、聚合和图例。结合读者任务选择主编码。 |
| ISO 图形及其他图标 | 为地点、服务或操作加符号，统一尺寸和线条以形成可辨识的版式。 | 采用 ISO 图形时记录符号编号、来源及含义，按目标情境测试识别。 |

| 叙事段落 | 数据字段或素材 | 图形标记与视觉通道 | 版面处理 | 校对点 |
