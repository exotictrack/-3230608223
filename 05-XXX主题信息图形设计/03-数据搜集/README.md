# 03 数据搜集

按来源登记候选材料，优先搜集能回答主问题的字段，并记录证据在哪一页、哪张表或哪个文件。

| 来源 | 收集内容 |
| --- | --- |
| [公用数据集](01-公用数据集/README.md) | 可下载的开放数据、官方统计、开放地理数据等。 |
| [文本文献](02-文本文献/README.md) | 论文、档案、报道、书籍、史料及图像的出处和摘录。 |
| [自建数据集](03-自建数据集/README.md) | 访谈、实地观察、人工编码、手工录入或自主采样的记录。 |

三类来源汇总时可共用「来源 ID、名称、发布方、覆盖范围、版本或日期、链接、使用条件、拟提取字段」这些记录项。数据进入基础表后保留来源 ID，以便回查原材料。
