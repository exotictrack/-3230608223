# 01 前期调研

从目标读者的问题出发，先确定研究边界和需要核实的材料。

| 调研项 | 记录 |
| --- | --- |
| 选题与研究对象 | XXX；范围包括哪些对象、地点和时期？ |
| 目标读者与使用场景 | 谁会读？海报、报告、展览还是网页？当时能用多少时间阅读？ |
| 主问题与次问题 | 读者看完应该能回答哪一个问题？哪些事实需要补充背景？ |
| 对照案例 | 记录来源、作者、可见的图形特征、阅读路径与值得借鉴的做法。 |
| 证据与缺口 | 写下已掌握的事实、待核实的说法、能取得的量化数据、文本与图像。 |

把调研结果浓缩为一句设计命题。可用句式为「面向____，在____场景中，用____证据回答____」。
