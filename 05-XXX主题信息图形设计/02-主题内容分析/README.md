# 02 主题内容分析

把研究对象、资料样例和读者问题交给大模型讨论。在同一页记录候选判断、依据、待核实处和采用理由，资料增加后直接修订。

| 判断项 | 可以怎么问 | 示例标签 |
| --- | --- | --- |
| 数据逻辑 | 哪种关系支撑主问题？时间先后、分类编排、父子包含、字母顺序，还是空间位置？ | 编年型、编目型、层级型、字母表型、地理型 |
| 表现类型 | 读者主要通过什么看到信息和线索？ | 文字型／列表型、照片型／图片式、时间轴型、单一图表型、混合型 |
| 视觉风格 | 整个版面采用何种图像语言？ | 平面图形风格、纪实照片风格、照片与平面图形混合 |
| 局部图形与标签 | 哪个图形能承载一个具体的量、类别或关系？ | 词云图、条形图、时间轴、点位地图、照片注释 |

一个项目可以同时使用不同层次的标签。例如，按词项组织可暂归「编目型」，整体以短文与列表阅读可归「文字型」，其中的词频可用「词云图」表达。若主版面依赖照片解读，另判断「照片型／图片式」是否为主表现类型。词云的字号若承担统计编码，需要找到词频或权重依据。

## 与大模型讨论的起点

> 我在做「XXX」主题的信息图形。目标读者是____，我希望他们能回答____。现有资料与字段样例为____。请根据这些材料分别判断主次数据逻辑、主要表现类型、视觉风格与可用的局部图表。给出每项判断的依据、备选方案、待补字段和一个能区分方案的问题。涉及具体数据时，请标明已有证据和待核实内容。

| 讨论结果 | 当前选择、依据或待核实问题 |
| --- | --- |
| 主数据逻辑与次数据逻辑 | 待填写 |
| 主表现类型与视觉风格 | 待填写 |
| 具体图形及标签 | 待填写 |
| 采用理由与补证需求 | 待填写 |
