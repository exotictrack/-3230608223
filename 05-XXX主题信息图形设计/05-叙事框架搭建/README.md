# 05 叙事框架搭建

每段叙事先写一个读者问题，再选能回答它的字段。记录筛选、排序、汇总和比较范围，让叙事结论能回到基础表核算。

| 叙事问题 | 字段组合 | 能表达的结论及所需上下文 |
| --- | --- | --- |
| 这些地点在哪里？ | 地点名称＋经度＋纬度 | 名称与 GPS 点位配合，可在地图上标注地点。应记录坐标参考系与底图来源。 |
| 某地的 GDP 是多少？ | 地点名称＋GDP 数值；附年份、单位与来源 | 可做一个地点的数值标注，或在同一时期、单位和统计口径下比较多个地点。 |
| 主题词有哪些？ | 词项＋词频或权重；附语料范围 | 可核对高频词或权重分布。若采用词云，字号映射和语料处理应可回查。 |
| 照片能说明哪个地点或事件？ | 对象 ID＋图像引用＋说明文字＋拍摄时间／地点 | 用照片和注释交代对象与情境。照片说明应有可核实的来源。 |

把选中的叙事段按读者的阅读顺序排列，例如「交代情境 → 呈现重点 → 给出必要的对照」。用下表检查每一段是否有实际数据支撑。
