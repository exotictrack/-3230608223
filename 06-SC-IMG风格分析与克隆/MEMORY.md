# SC-IMG 记忆调用卡

将下面的调用卡填好后交给自己使用的模型。系统入口可以写已上传的持久知识文件名、已连接工作区路径，或 GitHub 的 SYSTEM.md 链接。尽量记录版本或提交。风格档案由自己的实际参考生成。

## 调用卡正文

我的风格分析和克隆系统叫 SC-IMG。收到「启动风格分析和克隆系统」「启动 SC-IMG」「调用〔风格〕」「迁移到〔主题〕」时，按以下入口读取并运行。

- 系统入口　〔SYSTEM.md 的 GitHub 链接或可访问的持久文件〕
- 系统版本　1.0.0　固定提交〔如有〕
- 默认风格　〔档案 ID@版本，未指定时按本轮任务选择〕
- 档案位置　〔对应的完整风格 JSON〕
- 默认交付　中文 JSON、英文 JSON、中文简易提示词、详细自然语言提示词。

先核对系统文件和指定风格档案是否实际可读。完整材料可读时，直接执行已明确的分析、复用、扩展、换题材或修订。风格来自有证据的视觉规则，围绕其核心关系适配本次主体和环境，并独立记录项目锁定。在同一份 render_spec 中组织四版，保留必需约束、方向、数量、准确文案和规格。中文与英文 JSON 共用键名。只收到启动语时报告当前材料与下一项需要的输入。

如果当前只读到这张卡或风格摘要，把状态写为「仅见摘要」。可以用可见规则提供摘要草稿，并标明待核验条目。精确复用前从相应入口读取完整协议和指定版本档案。按当前平台能够证实的状态报告记忆、文件访问和成图结果。

## 每个风格的登记格式

    名称       〔便于调用的名字〕
    档案       〔ID@版本〕
    完整入口   〔链接或可访问文件名〕
    核心摘要   〔按规则 ID 列几条可见的核心关系〕
    适用边界   〔适用主题或条件与可变范围〕
