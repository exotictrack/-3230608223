# 01 编年型信息图形：概念定义

## 核心判据

信息单元的主关系由**时间位置、先后顺序、间隔、持续时长或时间过程**决定；改变时间字段或顺序就会改变作品要表达的核心含义。最小数据单元可以是事件、时期、时间点测量或持续过程。与纯粹的“时间轴型”版式不同，编年逻辑也可能用折线、日历热力图或地图动画表现。

## A. 基本数据逻辑

- **基础模式**：`事件ID | 实体ID | 开始时间 | 结束时间(可空) | 事件类型 | 数值(可空) | 时间精度 | 证据来源`。时间点是 `start=end` 的特例，但显示为瞬时事件；事件间可以有并行与嵌套。
- **关系本质**：`before/after`、`overlap`、`duration`、`same-period`、`change-over-time`。先后顺序是序数关系，时长是可度量差值，不得混淆。
- **尺度问题**：年/月/日/时应统一或显式转换；年代不确定的记录需要区间或“约”标识。离散序列与连续时间测量须分开。
- **必要区分**：时间先后不自动证明因果；多个事件并列不代表同权重。没有明确时间字段的步骤清单不必然属于编年型。

## B. 统计图形与计算方式

| 数据任务 | 可借用的统计图形 | 计算或约束 |
| --- | --- | --- |
| 事件发生时刻 | 时间轴、事件点图、rug plot | 统一时间基准、处理并发与同日记录 |
| 持续过程 | 区间条 / 甘特式条带 | `持续时间 = 结束 - 开始`，注意时间精度 |
| 数量变化 | 折线图、阶梯图、面积图 | 同口径测量；`增量 = 本期 - 上期`；`增长率 = 增量/上期`（上期为零不可直接计算） |
| 周期比较 | 日历热力图、分面小多图、箱线图 | 相同时间粒度、可比的分组与观察窗口 |
| 累积进程 | 累积曲线、堆叠时间系列 | 累计值单调性核查；堆叠项口径互斥且完整 |

统计方法可涉及时间分箱、移动平均、同比/环比、变化率、插值等；平滑或插值必须披露方法，不能把估计点伪装为实测。

## C. 视觉编码：点、线、面、体、符号、色彩

| 变量 | 推荐编码 | 风险控制 |
| --- | --- | --- |
| 点 | 用点表示事件发生时刻、里程碑、异常峰值 | 密集事件应避让或分组，不移动真实时间位置而不注明 |
| 线 | 时间轴、进程线、数值轨迹；线型区分事实/预测 | 不能因连线制造不存在的连续观测；必要时画断线 |
| 面 | 区间带表示持续时间；面积图表达总量/组成 | 面积与数量的关系需按比例，不用装饰面积误导 |
| 体 | 轴测或三维插画可强化事件场景 | 体积、透视不能替代精确的数值刻度 |
| 符号 | 同类事件用固定图标语法，附图例 | 图标应语义一致、避免象形尺寸暗示错误数值 |
| 色彩 | 对类别用离散色，对强度用有序色；重点时刻强调色 | 不仅依赖颜色区分；对比度、色盲可读性与打印适应性 |

**关键规则**：若是等距时间刻度，图上距离必须与真实时间差相符；若改用等距节点布局，应明确标为“事件顺序图（非按时间比例）”。

## D. 数据 / 信息架构

1. **底层事实**：原始事件、时间点指标、元数据（来源、统计口径、精度）。
2. **关联层**：按实体与时间字段排序、去重；建立阶段、前后/并行及类别关系。
3. **分析层**：分期、聚合趋势、找转折点/异常点；每个推导标记方法。
4. **呈现层**：主时间线 + 重点事件卡片 + 对照量尺 + 注释/出处；辅助数据不抢主线。
5. **检索层**：多条并行时间线可按人物、地区、主题筛选；长序列应有导航锚点。

## E. 视觉叙事架构

推荐组织：**背景时段 → 起始条件 → 阶段变化 → 转折/对照 → 结果与未解问题**。可用“从宏观年代到局部事件”的缩放讲述，也可让多条并行事件形成对照。首屏应说明时间跨度、对象和证据范围；结尾标注“相关”与“因果”之间的区别。

## 辨识检查与常见误判

- 若删除时间字段，图的核心关系是否仍成立？若仍成立，可能只是采用时间轴外观的编目表。
- 时间间隔是否被等距节点替代？若是，必须披露布局的非等比例性质。
- 事件取舍是否服务叙事却牺牲完整性？应说明筛选标准，避免制造必然进程。
