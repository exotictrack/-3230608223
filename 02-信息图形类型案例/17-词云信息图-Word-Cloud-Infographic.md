# 17 词云信息图（Word Cloud Infographic）

词云以一组可辨认的文字构成图面，读者通常先注意到字号较大、颜色较强或位置醒目的词。对于统计词云，**词项**是基本数据单位，**字号**可以编码词频或预先定义的权重。

- **表现类型**：可视化文本型。
- **案例编号**：CASE-0017。现阶段将数据逻辑暂归编目型，待作品原图和数据补齐后核验。
- **证据状态**：待补原图、出处、语料或词频表。收到的截图用于定位仓库目录，案例观察待原图补充。

## 识别与分析

| 看什么 | 记录哪些证据 |
| --- | --- |
| 词项从哪里来 | 写明语料范围、语言、分词和筛选规则，确认每个词对应的频次或权重。 |
| 大字代表什么 | 有可追溯的权重和字号映射时，可判为统计词云。若资料仅能证实手工安排的字体层次，可暂记为词云式排版。 |
| 颜色、位置和旋转有何作用 | 按图例或制作说明判断颜色是否表示类别，聚集或旋转是否有数据含义。缺少说明时，先记录可见的布局特征。 |
| 怎样比较词频 | 用源数据核对排序。字号、字数与字体会共同影响文字面积，需精确比较时可查看词频表或排序条形图。 |
| 阅读顺序如何形成 | 记录第一眼看到的词、后续扫读路线、图例或说明所在的位置，并核对它们是否共同支持作品主题。 |

收到原图后，先在原有案例记录补入可辨认的词、颜色与位置等观察，再比对语料或词频表、检查字号映射、更新证据状态。作品出处与使用许可核实后，可按案例编号关联配图。
