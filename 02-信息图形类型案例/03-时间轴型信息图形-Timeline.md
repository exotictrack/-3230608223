# 03 时间轴型信息图形（Timeline Infographics）

## 1. 定义与双层区分

时间轴型是一种**以时间线、阶段线或历程路径引导阅读的表现形式**，可用横向、纵向、曲线、环形或多轨布局。它最常呈现编年数据，但也可能是“非等比例的步骤序列”；所以分析时必须同时判定**画面形态**与**时间数据本质**，不要把视觉上的节点顺序直接等同于真实时长。

## 2. 核心数据结构

最小条目可记为 `事件ID | 年月日/时间段 | 实体 | 标题 | 事件描述 | 主题轨道 | 证据 | 精度`。重要关系包括：先后、并发、持续、分期、关键转折、跨轨对照。若仅有“第一步、第二步”而无时间字段，应列为步骤序列型，视证据决定是否算时间轴。

## 3. 可借用的统计图形与计算

- **事件时间轴 / 点图**：对已知发生时刻的事件进行定位。
- **区间条 / 甘特图**：表示活动持续时间（结束减开始），不同时长应有可比的长度标尺。
- **折线、面积、阶梯图**：在时间轴旁表达连续数值变化，说明采样频率和缺测期。
- **累积线或按时期的柱状图**：表达累计数量、各时期发生频次。
- **事件密度图与年历图**：比较不同周期的发生频率；需控制观察窗口和采集偏差。

计算可能用时间间隔、累计总量、移动均值、同比/环比等；可视情况用同一纵轴并列不同年份，但应写清图表基线、刻度与数据来源。

## 4. 视觉编码：轴、节点与时间比例

| 元素 | 信息职责 | 典型风险 |
| --- | --- | --- |
| 点 | 里程碑或单次事件 | 无法区分日期不确定和精确日期 |
| 线 | 事件顺序、时间标尺、数值趋势 | 线条弯曲造成“时距”错觉 |
| 面 | 时间段、阶段背景、聚合窗口 | 区间宽度不对应持续时间而没有说明 |
| 体/场景 | 某一年代的文化/空间语义 | 不同尺寸的插画被当作事件重要性的测量 |
| 符号 | 事件类别、技术、人物、地点 | 图标规则随意变化 |
| 色彩 | 阶段区分、多轨实体对照、强调转折 | 不同轨道使用相同颜色却含义不同 |
| 文字 | 日期、概述、时间精度、出处 | 时间标签堆叠导致漏读或误读 |

**双模式说明**：`按时间比例（metric timeline）` 必须保证间距与时距成比例；`按事件次序（ordinal timeline）` 允许等距节点，但须显式声明“仅表示顺序，不表示时间间隔”。

## 5. 信息架构

设置时间范围与主题 → 整理按日期排列的事件表 → 对事件分期和分轨 → 选择时间比例或顺序排列 → 安放重点事件的注释 → 形成主线与辅助数据的层次。若跨多个文化或机构轨道，明确同时发生的事件如何对齐；变换比例时标注断轴或局部放大。

## 6. 视觉叙事结构

可采用**起源 → 发展 → 关键转折 → 新阶段 → 影响**，或**两条并行进程 → 差异出现 → 时间差与结果**。时间轴天然具有方向性，但“看似必然发生”的故事可能隐藏被删去的反例；应解释事件选择与遗漏的标准。

## 7. 案例分析判定清单

- 时间轴是横向、纵向、环形还是自由路径？时间是否按比例布局？
- 是否存在多条轨道、双重时间尺度、年代分期与局部放大？
- 节点、线与插画共同承担什么信息？阅读起点和终点是否明确？
- 对比不同跨度的历史时，是否有错误的空间均匀排列？
- 画面表达的是“何时发生”，还是“怎样一步步完成”？

## 10. 制作方法（待案例校验）

先整理真实时间表；选定**时间比例轴**或**顺序轴**；再做分期、重点筛选、多轨对照，最后添加人物/物体/符号插画与注释。每增加视觉效果，都检查它是否改变时长、同期性或统计量的可读性。
