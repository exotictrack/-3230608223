# 课件方法论：信息图形设计、评价与修订规范

> 依据用户上传《第三讲—信息图形类型学(2).pdf》第40–72页整理。课件表述、对原意的操作化延展，以及外部核验分开注明；这不是对课件插图的统计实验复现。

## 1. 选题与受众匹配（课件40页）

- 数据性质必须与表达形式匹配（不能把分类关系画成精确时间进程）。
- 预期读者的背景知识与视觉形式的解码负担匹配；专业读者可承担更多专业信息。
- 以叙事性与趣味性为吸引入口，但最终服务可解释的信息。

## 2. 设计工作流（课件43页）

1. **数据收集与清洗**：标出来源、缺漏、异常、定义和统计口径。
2. **数据集与结构搭建**：用编年/层级/编目/字母表/地理等逻辑确定主要信息关系。
3. **视觉编码与版式排布**：选择图表、色彩、符号、标注与次级阅读层。
4. **数据关联与内容呈现**：在可追溯的数据关系之上建立叙事，回检结论是否被证据支持。

此四步保留课件顺序，不先选一个酷炫图形再寻找数据装填。

## 3. 四大常见误区（课件44页）

| 课件原概念 | 可操作审查 | 典型修复 |
| --- | --- | --- |
| 太复杂（数据没看懂） | 变量定义、分母、关系不清楚 | 先补数据字典与主问题 |
| 太抽象（看懂了，没考虑读者） | 读者不知道符号或结论为何重要 | 加入注释、示例和背景 |
| 无美感 | 视觉层级、对齐、对比欠佳 | 统一网格、色系和排版等级 |
| 内容多（数据整合没做好） | 主次没有区分，重复指标过多 | 分层浏览、去重、信息摘要 |

## 4. 评估维度与可视化轮盘（课件45–53、69页）

课件并置 **抽象/模拟、实用/修饰、致密/稀疏、多维/单维、创新/通用、简洁/冗余** 的平衡方向。这些是设计取舍，不宜机械理解为“越左/越右越好”。

- 先展示整体/数据概要，再允许读者进入内部细节，最后提供自由探索的导航（69页）。
- 阅读路径可测试：主题是什么、展示哪些参数、强调如何变化、是事实还是观点（42页）。
- 课件描述眼动与短期/长期记忆测试（5分钟、2周），是**测试思路**而非本仓库已经实施过的实验。没有受试者、样本量和原始数据，不报告显著性或“实验证明”。

## 5. 数据/油墨比与“图表垃圾”（课件54–57页）

- 课件公式：**数据/油墨比 = 用于呈现数据的油墨 / 图表总体油墨**。
- 此比值是帮助检查冗余标记的启发式原则，不是“删去标题、单位、图例和出处就更好”的强制算式；必要的理解成本也是设计性能。
- “图表垃圾”应关注会误导、遮挡、重复或无意义增加认知负担的元素；语义明确、帮助理解的插图不能仅因其装饰性被一概否定。
- 外部校验：欧盟数据可视化指南 [Chart junk and data ink](https://data.europa.eu/apps/data-visualisation-guide/chart-junk-and-data-ink-origins)（阐述Tufte的数据油墨比）。

## 6. ISOTYPE：不是 ISO 标准、也不是 isometric（课件58–61页）

[18 ISOTYPE 基础设计方法标签](18-ISOTYPE-基础设计方法.md)收录其具体编码方法、单位示例和案例判定依据。

- 课件将 Otto Neurath（奥图·纽拉特）与 ISOTYPE 连接，并介绍视觉公共教育。
- **术语核验**：1920年代起初称 **Vienna Method of Pictorial Statistics（维也纳图画统计法）**；1935年前后采用 **Isotype（International System of Typographic Picture Education）** 这一名称。不能把“1925年开始实践”直接写成“1925年已以Isotype名称发表”。
- 三个概念须分开：**ISOTYPE** = 具有统计教育方法论的象形符号系统；**ISO公共信息符号** = 依据特定标准制定的图形；**isometric/轴测图** = 一类空间绘图投影方法。
- 象形图重复单位需固定代表量且计数可复核；有图标不自动等于 ISOTYPE。
- 外部核验：[维也纳大学 Isotype 项目](https://isotype.univie.ac.at/en/abstract/)；[Smithsonian Cooper Hewitt 专文](https://www.cooperhewitt.org/2024/01/12/a-reminder-about-isotype/)。

## 7. 深度挖掘与表达边界（课件62–72页）

- 课件强调信息表达、挖掘、深度与设计传达的平衡（64–65页）；“信息清晰”不等于删减掉必要证据（67、70页）。
- 先确定数据组织结构，再考虑风格；检查修饰是否挤占论据空间（70–71页）。
- 用 **客观图示/研究者解释/外部核验** 三种标记区分证据层次；不因为版面有吸引力就宣称因果或统计可靠。
