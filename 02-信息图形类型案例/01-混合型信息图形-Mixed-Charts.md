# 01 混合型信息图形（Mixed Charts）

## 1. 定义与边界

混合型信息图形不是“画面中有两张统计图”这么简单，而是**把一个或多个可验证的统计编码系统与解释性图形、图标、空间隐喻、文字注释及视觉叙事组合成一条完整的信息论证路径**。其核心问题是：如何保留统计图形的计算真实性，同时让抽象数值进入容易理解的主题情境。

**与一般统计可视化的区别是设计重心，不是绝对二分**：常规数据可视化也可能叙事、注释和使用图标；本研究称“混合型”的判据，是数值编码与具语义的图像元素**共同承担解释任务**，非图表装饰数量。仅把卡通贴在柱状图旁边，不足以证明混合有效。

用户所说“ISO 图形”存在术语歧义：可能指 **ISO 标准化 pictogram/公共信息符号**，也可能是 **isometric（等距轴测）图形**。在案例分析时必须根据图片判断所指，不预先将两者认作同一概念。以下统称“语义图形/符号”，必要时分别标注 `standard-pictogram` 与 `isometric-illustration`。

## 2. 结构拆解：数据 → 计算 → 视觉 → 叙事

| 层级 | 需要分析的内容 | 典型问题 |
| --- | --- | --- |
| 原始数据层 | 指标、维度、单位、分母、取样范围、来源 | 是计数、百分比、等级还是事件顺序？ |
| 统计转换层 | 聚合、排序、归一化、占比、增长率、映射比例 | 计算是否可复现，是否因为图形变形产生错觉？ |
| 图形编码层 | 条长、位置、面积、角度、方向、线宽、色阶 | 哪些尺寸真正在编码数值？ |
| 语义符号层 | 人物、建筑、器物、ISO 图标、轴测小场景 | 符号如何解释对象、空间或行为？ |
| 视觉叙事层 | 标题主张、视觉焦点、先后阅读、说明、结论 | 画面是否形成可被证据支持的论点？ |

## 3. 常见组合机制（待案例验证的设计模式）

1. **统计骨架 + 图标点题**：用严谨条形/折线承担数值，图标解释测量对象。要核实图标不暗示另一个刻度。
2. **象形单位 + 数量重复**：一个固定图标代表固定数量，以图标重复呈现频数。非整数与残余必须明确处理；勿随意缩放图标。
3. **轴测场景 + 嵌入式数值标尺**：先用空间场景建立主题，再以独立尺度的标尺比较数据。透视物件不可单靠表观大小代替定量编码。
4. **地图/流程 + 辅助统计图**：一个图形解释“在哪里/如何发生”，另一个解释“有多少/如何变化”；阅读路径要兼顾空间和数值。
5. **多个统计图 + 共同故事**：图表之间共享实体、时间窗和问题框架，用注释连接因果假设与不同证据，不重复堆砌。

这些是**可能的分析类别，不是已发现的案例规律**。

## 4. 视觉编码分析表

| 视觉元素 | 可承担的合法功能 | 典型失败方式 | 建议的验证方式 |
| --- | --- | --- | --- |
| 点 | 观察值、单位对象、事件 | 点大小随意变导致量错觉 | 找出数值对应的点数量或刻度 |
| 线 | 变量关系、方向、路径 | 装饰线像趋势线；流向线宽没有依据 | 比较图例、起终点和线宽 |
| 面 | 比例、区域、图块容器 | 面积/半径/体积混用 | 检查编码变量及比例规则 |
| 体 | 轴测景观、3D 场景 | 透视遮挡数值差异；夸张体积 | 是否有独立的二维量尺和数字标注 |
| 符号 | 引导对象识别、类别语义 | 图标风格不统一、歧义严重 | 图例、对象与图标的一一映射 |
| 色彩 | 分类/顺序/情绪层级 | 情绪色与数据色冲突 | 是否有一致的分组逻辑与可访问替代标签 |
| 文字 | 指标标题、旁注、解释、来源 | 标语结论超出数据支持 | 逐条核对句子与图表证据 |

## 5. 信息架构与视觉叙事

- **推荐信息层次**：研究问题/核心结论 → 主要指标图 → 语义情境 → 关键细节解释 → 数据/方法/来源。采用数据为主还是场景为主，取决于案例的首要任务。
- **阅读路径模型**：主题入口 → 情境设定 → 核心数值对照 → 异常/原因解释（只写有证据的部分）→ 可行动结论。允许局部跳读，但读者不应找不到统计尺度。
- **融合评估**：`真实性`（可核算）× `语义必要性`（符号是否产生信息）× `阅读效率`（是否降低理解成本）× `美学一致性`（风格与主题是否协调）。这些是评价维度，不是可直接相乘的科学分数。

## 6. 案例分析的重点取证

1. 统计图形具体用了哪一类？轴、比例、单位、基线是否完整？
2. ISO/轴测/图标元素具体是什么？对数值与分类是否有真实信息贡献？
3. 数据要素与语义要素是什么耦合关系：共用位置、嵌入式、叠加、并置、串联？
4. 视觉叙事的起点和终点在哪里？是否存在用图像暗示而未证实的因果？
5. 若删掉装饰图形，结论是否仍清楚？若删掉统计图形，结论是否仍可核算？

## 9. 可执行的制作方法（初稿）

先写清楚一个主问题和指标口径；再画**不带插画的可核算图表**；接着选择真正解释主题的语义元素；最后用引导标题、注释、留白和色彩建立故事路径。检查两个层次删除前后信息损失的程度：能互补而非互相遮挡，才是有效混合。
