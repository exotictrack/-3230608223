# 13 可视化简历型信息图形（Visual Resume Infographics）

> **证据边界**：本说明以用户上传的《第三讲—信息图形类型学(2).pdf》第 34 页作为图像观察来源；课件截图能支持图形构成与版式描述，但未经原始作品/数据验证的作者、数值与效果均不作为事实。

## 课件图例的可见特征

两例都以人物头像、技能块、教育及经历模块构成个人信息页面，右例强调巨大纵排字与红色模块。

## A. 数据逻辑与最小结构

记录`经历ID｜时间段｜机构/职位｜技能/等级｜证明材料`；个人履历多含时间、分类与自我陈述。

## B. 借用的统计图形与计算方式

工作年限和技能数量可以量化；自评技能条并非客观测试，需注明评价尺度和来源。

## C. 视觉编码（点、线、面、体、符号、色彩与排版）

时间线提示经历顺序，色块区分教育/技能/工作，头像与大字塑造识别；不要让排版强势夸大未经核实的能力。

## D. 数据／信息架构

个人定位→主要能力→经历时间线→项目/成果→联系方式与来源。

## E. 视觉叙事架构

是谁→擅长什么→有哪些证据→适合什么岗位；优先清晰和准确而非复杂装饰。

## 边界与待核实事项

不能仅凭技能条长断言真实熟练度；课件也未提供可核验履历源。

### 扩展定义与判据

视觉简历信息图形以个人为叙述对象，将身份定位、教育背景、工作或项目经历、专业能力、成果及联系渠道组织为可快速浏览的视觉页面。通过模块分区、时间顺序、图标、字体层级和视觉强调，建立“我是谁—我能做什么—有哪些经历或成果支持—如何进一步了解我”的阅读关系。

它可组合时间轴、列表、摄影、手写标注与拼贴，不以包含统计图表为必要条件。个人风格参与职业形象表达，能力判断仍需经历、项目与成果支撑。两例支持“整体编目、局部编年”的组织方式；字体大小构成视觉层级，不自动构成层级型数据逻辑。

扩展字段：`信息类别｜时间范围｜角色/机构｜专业方向｜工具｜成果说明｜证明入口｜评价依据`。专业方向、软件工具、熟练程度应分开；证明入口和评价依据不得与自我陈述混同。

### CASE-0018 履历结构主导的拼贴式视觉简历

- 来源：用户提供 `Visual Resume简历1.png`，2026-11-27；页面姓名 Aravindh A。
- 媒介：竖版静态图；实际印刷尺寸未知。主要模块可辨，顶部细字较小。
- 主逻辑：编目；次逻辑：编年。主表现：Visual Resume；辅助：时间轴、文字列表、摄影、手写与拼贴。判定信心：高（仅限可见结构）。

#### A. 数据逻辑与最小结构

顶部集中姓名、肖像、简介和联系信息；下方左栏为工作、教育，右栏为专业方向、软件技能。最小经历记录为 `时间段｜职位或学历｜机构｜任职性质或学习信息｜补充说明`。工作经历由近及远排列，节点和虚线建立顺序；没有连续时间刻度，节点距离不应解释为任职时长。整体仍按信息类别组织，编年是局部关系。

#### B. 统计图形与计算方式

软件图标下有不同长度的技能条，可解释为自评程度表达，但没有刻度、满分、评价方法和来源，不能推算熟练度百分比。教育成绩为文字数值，不与技能条共用尺度。不依据图中“Present”推算当前工作年限，作品时间待核实。

#### C. 视觉编码

| 元素 | 图上证据 | 作用与边界 |
| --- | --- | --- |
| 点与线 | 左栏经历节点、虚线；顶部联系信息边框 | 提示顺序和归组，不表示等比例时间 |
| 面 | 双栏结构；右栏彩色专业方向纸片 | 分区、分类；纸片面积不编码能力 |
| 体 | 纸张、回形针、撕边和阴影 | 手工材质与空间感，不编码数量 |
| 符号 | 软件标志、电话和邮箱图标 | 类别识别；不是单位计数的ISOTYPE |
| 色彩 | 黄色栏目标题底、绿色局部强调 | 导航和重点，不代表统一数量尺度 |
| 文字 | 姓名、栏目、职位、机构与小字分级 | 建立检索层级；顶部小字可能影响阅读 |

#### D. 数据／信息架构

个人身份与简介 → 工作经历／专业方向 → 教育背景／软件技能；联系入口集中于顶部。顶部身份区与下部双栏支持按需检索。经历、技能与联系方式属于不同字段组，不宜互相替代。

#### E. 视觉叙事架构

以人物身份进入，再以工作、教育和技能建立职业概览。右上手写联系邀请突出联系入口。可迁移方法：稳定网格保证信息组织，少量手工元素增加辨识度。技能条尺度缺失、顶部信息密集、专业方向缺少项目对应证据，是该案例的主要限制。尚未开展阅读效率测试。

### CASE-0019 个人品牌主导的场景式视觉简历

- 来源：用户提供 `Visual Resume简历2.png`，2026-11-27；页面姓名 BERI / BẢO TRÂN。
- 媒介：竖版静态图；实际印刷尺寸未知。主要模块可辨，二维码未解码验证。
- 主逻辑：编目；次逻辑：局部编年（时间属性与局部顺序）。主表现：Visual Resume；辅助：文字列表、摄影、手写和拟物拼贴。判定信心：高（主类型与编目）；中（次级编年强度）。

#### A. 数据逻辑与最小结构

大幅照片与姓名建立身份焦点；个人介绍、经历、教育、证书、软件为独立模块。经历区混合自由职业、竞赛、学校项目，不是统一尺度的职业时间线。最小记录为 `条目类别｜名称｜时间｜角色或说明｜对应成果`。年份提供背景，不应把整个页面判作时间轴。

#### B. 统计图形与计算方式

软件区是工具图标集合，没有等级或数量比较；插画、平面设计、品牌设计、摄影标签表示类别，不表示能力排名。未见可复算的统计编码。工具数量不代表能力强弱，经历与证书中的年份不自动构成统计图表。

#### C. 视觉编码

| 元素 | 图上证据 | 作用与边界 |
| --- | --- | --- |
| 点与线 | 手绘星形、箭头、边框 | 装饰和局部引导，无时间轴或数据连线 |
| 面 | 便签经历区、信封联系方式、纸条能力标签 | 容器同时分组和提示语义 |
| 体 | 卷纸、叠压、投影和夹具 | 模拟实物空间；不表示数量 |
| 符号 | 软件标志与二维码 | 工具识别及外部入口；二维码不是已验证的成果 |
| 色彩 | 绿黄贯穿、红蓝等辅助色 | 个人风格与模块区分，无统计色阶 |
| 文字与摄影 | 超大姓名、大幅肖像、重复椭圆栏目标签 | 身份识别与导航；字号不编码能力等级 |

#### D. 数据／信息架构

身份与联系入口 → 个人定位 → 经历／教育及专业方向 → 证书或成果说明 → 软件工具。纵向展开结合局部并列，信息嵌入个人展示板／手账式场景。软件图标若缺少名称，会增加不熟悉工具的读者的解码负担。

#### E. 视觉叙事架构

照片、姓名、配色先建立人物印象，再展开背景与能力。页面可作为视觉表达方式的观察材料，但不能单凭风格推断完整职业能力。可迁移方法：把信息模块与有语义的物件结合，让个人风格参与组织。大幅肖像与装饰占用空间、经历性质混合、部分项目缺少职责和产出，是应用边界。

### 跨案例方法与反向修订

| 候选条款 | 证据 | 适用边界 |
| --- | --- | --- |
| 整体编目、局部编年 | CASE-0018 双栏分类与经历顺序；CASE-0019 模块与年份 | 有日期不等于连续时间轴 |
| 非统计视觉组织也可构成视觉简历 | CASE-0019 无明确统计图表仍形成结构化信息 | 装饰形状不能强行解释成图表 |
| 专业方向、工具、熟练程度分开记录 | 两例均有方向与软件，仅0018有技能条 | 自评条不证明客观熟练度 |
| 拟物容器兼具分组和语义提示 | 两例纸片；0019信封与便签 | 阴影和叠压不得遮挡内容、暗示虚假数量 |
| 联系入口属于信息架构 | 两例联系方式与二维码 | 入口存在不等于链接有效或履历真实 |
| 评价兼顾检索、个人识别与证据完整性 | 0018偏履历扫描，0019偏人物印象 | 未测试，不声称提高招聘成功率或阅读效率 |

以上为两例支持的候选方法，不是普遍规律。拼贴属于共同风格而非类型必要条件。建议制作时先确定信息字段与证据，再组织分区和阅读路径，最后配置个人风格；检查缩小后的文字、图标名称和证明入口是否可用。
